# 正文配图（千问27B → Krea2）

酒馆扩展：把**当前楼层正文**发给 **Qwen3.8-27B Q4**，让它写多条分镜出图提示词，再用 **Krea2** 并发出图，一张图讲一段故事。

## 依赖

本机 **H3 工作台**（默认 `http://127.0.0.1:8899`）提供三个接口：

| 接口 | 用途 |
|---|---|
| `POST /v1/chat/completions` | 用你填的 RunningHub Key 调千问27B |
| `POST /api/krea2/run` | 提交文生图 |
| `GET /api/krea2/history` | 查结果 |

出图落在 `D:\h3工作台\kera2\output\`（按面板分开存）。

## 安装

酒馆 → 扩展 → 安装扩展 → 填仓库地址，或者把本文件夹放进：

```
~/SillyTavern/data/<user>/extensions/sillytavern-story2img/
```

刷新页面，右下角出现 **🖼** 按钮即装好（在 🎬 上方）。

## 用法

1. 点击 🖼
2. 填 **H3 地址**（默认 `http://127.0.0.1:8899`）和 **RunningHub API Key**（只存浏览器本地）
3. 选楼层（默认最新一条）→ 选**张数**（1–8）、**画风**、**画幅**、**并发**（1–6）
4. 点 **① 生成提示词** —— 千问按正文时间顺序写 N 条英文分镜提示词（可直接手改）
5. 点 **② 出图** —— Krea2 并发出图，约 40–90 秒/张
6. 卡片右上角「原图」可下载

## 提示词口径

千问收到的系统提示要求：

- 每行一条英文提示词，纯文本、无编号
- **必须有角色**（这是故事插图，不是空场景），按正文顺序覆盖关键情节
- 角色用固定写法：年龄 + 发型发色 + 瞳色 + 衣着（保持前后一致）
- 每条含：动作表情 + 环境陈设 + 光线时间 + 色调材质 + 镜头
- 不要文字/字幕/水印/UI

## 成本参考（实测）

| 步骤 | 币 | 时间 |
|---|---|---|
| 千问写 2 条提示词 | ~5 | 25–40s |
| Krea2 单张 16:9 | ~9 | 40–90s |
| 2 张并发 | ~18 | ~60s |

## 已知限制

- 千问上下文约 11,000 字，超长正文会被保头保尾截断
- 出图不含角色一致性锁定（每张独立生成，同一角色可能略有差异）；要严格一致请用 H3 的四视图参考流
- 手机酒馆可用：APK v102 起自带 `/v1/models`、`/v1/chat/completions`（千问27B Q4），手机上把 H3 地址填 `http://127.0.0.1:8899` + 填 RunningHub Key 即可独立跑完整流程（不必连电脑）
## 账号导入

面板「账号」一行：

- **导入账号**：把 H3 工作台「导出账号」得到的 JSON 粘进去 → 导入到 8899 的 `accounts.json`
  （`POST /api/accounts/import`，同 key 幂等更新，不会重复添加）
- **账号下拉**：选某个账号 → 千问请求会带它的 key；选「（用上面的 Key / 服务端账号池）」则：
  - 上面的 Key 有值 → 用 Key
  - Key 也空 → 不带头，服务端自动用账号池第一个 key
- 出图（Krea2）始终走服务端账号池，与这里的 Key 无关
